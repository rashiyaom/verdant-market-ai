# VOLTRA Website Transformation

## Goal
Rebrand the complete public website from Farmora to VOLTRA while preserving the existing premium, minimal glass-morphism design language across desktop and mobile.

## What will change
- Replace all Farmora branding, agriculture copy, imagery, icons, navigation, metadata, and empty/error states with VOLTRA grid-intelligence content.
- Rebuild the home page as a clear product story: predictive hero, reactive-vs-predictive problem, intelligence pipeline, cinematic transmission-grid sequence, dashboard preview, explainable fault analysis, historical analytics, alerts, and preventive-action close.
- Transform the current Market page into a functional **Live Grid** operator view with searchable grid assets, health/risk filters, selectable segments, status visualization, and detailed component analysis.
- Transform the current AI Scan page into a functional **Prediction** workspace with live scenario controls, outage probability, predicted window, affected region, contributing risk factors, and a working analysis flow.
- Transform the About page into **Technology**, explaining monitored electrical, equipment, weather, and historical signals plus the ML intelligence pipeline.
- Update shared navigation and footer for VOLTRA and retain all current public URLs so nothing breaks.

## Interaction and visual behavior
- Use the existing soft neutral background, dark ink, electric lime accents, serif emphasis, glass surfaces, and compact pill controls.
- Add purposeful animated power-flow lines, anomaly pulses, status transitions, and chart motion with reduced-motion support.
- Make filters, segment selection, risk details, prediction controls, alerts, and calls to action work without requiring login.
- Keep layouts touch-friendly and readable on phones, tablets, and desktop screens.

## Technical details
- Build the grid visuals with responsive HTML/CSS and lightweight SVG diagrams; use Recharts for analytical charts already available in the project.
- Replace agricultural assets with purpose-built visual grid scenes generated for VOLTRA where photography materially supports the story.
- Keep all visual colors tokenized in the shared theme and add route-specific social/SEO metadata.
- Remove now-unused agriculture/AI crop code from the user-facing flow while avoiding backend work.

## Validation
- Verify every public page and navigation path at desktop and mobile sizes.
- Exercise the Live Grid selection/filter flow and Prediction analysis flow.
- Check for rendering, overflow, console, and route errors before completion.
